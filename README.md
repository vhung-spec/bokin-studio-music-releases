# Bokin Studio Music — bản cập nhật

Kho này chỉ chứa bộ cài mới nhất của Bokin Studio Music và tệp `update.json` (có chữ ký
`update.json.sig`) mà app đã cài đọc để tự cập nhật. Mã nguồn không ở đây. Bộ cài được mã hóa:
cần mã cài đặt (gửi kèm key bản quyền) mới cài hoặc giải nén được.

Bản mới nhất: **0.10.1** — `BokinStudioMusic-Setup-0.10.1.exe`
